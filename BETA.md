# 🧪 Jarvis FR — version bêta 1.1

Merci de tester ! La bêta s'installe **à côté** de la version normale (dossier `Jarvis-Mark-LV-beta`, raccourci « Jarvis BETA »), sans rien abîmer. Pas besoin d'avoir la version normale avant.

## 1. Avant de commencer

- Installe **[Obsidian](https://obsidian.md)** (gratuit).
- Prépare ta **clé Gemini gratuite** : [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → « Create API key » → copie-la.

## 2. Installer la bêta

Ouvre **PowerShell** (menu Démarrer → tape *PowerShell*), colle cette ligne avec le bouton **copier** à droite du cadre, puis appuie sur **Entrée** :

```powershell
irm https://raw.githubusercontent.com/fredo-jarvis/jarvis-fr/beta/installer.ps1 | iex
```

L'installation prend 5 à 10 minutes (la fenêtre reste calme, c'est normal), puis elle te demande ta clé Gemini.

## 3. Tester l'hologramme

Lance **« Jarvis BETA »** sur ton bureau, puis dis : **« Jarvis, montre-moi le cerveau en hologramme »**.

Devant ta webcam, essaie :
- **pincer** une bulle pour l'ouvrir, puis **attraper** et **lancer** les cartes ;
- **écarter les deux mains** pour zoomer, ou pour lire une carte en grand ;
- le **signe de paix ✌** pour tout remettre à zéro ;
- la touche **J** pour le mode Jarvis (il parle en français).

Sans webcam, tout marche à la souris (clic = ouvrir, glisser = déplacer, R = ranger).

## 4. Ton retour

Dis ce qui marche, ce qui bugue, et si possible joins une **capture d'écran**, là où tu as trouvé ce lien. Merci 🙏
